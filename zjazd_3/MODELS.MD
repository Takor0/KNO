# first 
## Warstwy:
- Input - 13 cech
- Dense (hidden_1) - 32 neurony, aktywacja ReLU
- Dense (output) - 3 neurony, aktywacja softmax
## Parametry:
- Loss function: Categorical Crossentropy
- Optimalizer: Adam
- Metrics: Accuracy
- learning rate: 0.001
- batch size: 32
- Accuracy: 80%
## Opis:
Bardzo prosta architektura, z jedną wartstwą ukrytą Dense
